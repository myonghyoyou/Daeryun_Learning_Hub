# 문제 은행 Hub — 사용자·관리자 테스트 매뉴얼

> 컷오버(프로덕션 배포) 이후 실제 서비스가 의도대로 동작하는지 사람이 직접 눌러보며
> 확인하기 위한 문서입니다. 자동화 테스트(999개)가 이미 통과한 상태이지만, 그건 코드
> 단위 검증이고 이 문서는 **실제 화면에서 실제 사람이 실제로 쓸 수 있는지**를 봅니다.

## 0. 이 문서 사용법

- 시나리오마다 **확인 항목**과 **정상 결과**가 있습니다. 정상 결과와 다르면 그 자리에서
  캡처하고 §5 양식대로 기록하세요.
- 순서대로 할 필요는 없지만, "일반 사용자" 파트를 먼저 끝내고 "관리자" 파트로 가는 걸
  권장합니다 — 관리자 파트 일부(계정 비활성화 등)가 일반 사용자 로그인에 영향을 주기
  때문입니다.
- 테스트 중 생기는 풀이 기록(`attempts`)은 **지우지 않아도 됩니다** — 오히려 이력·통계
  화면 검증에 필요한 실데이터입니다.
- 문제 데이터는 실제 722(724)문항입니다. 테스트라고 아무 문제나 막 골라도 되지만, 관리자
  파트에서 **새로 만드는 테스트용 문제·부서·계정은 끝나고 정리**하거나 이름에 `[테스트]`
  를 붙여 구분하세요.

### A5. 문제 풀이 — 5개 유형 전부 확인

같은 세트 안에서 다 나오지 않을 수 있으니, "골라서 풀기"의 유형 필터(있다면) 또는
여러 세트를 통해 5가지 유형을 각각 한 번씩은 풀어보세요.

| # | 유형 | 확인 항목 | 정상 결과 |
|---|---|---|---|
| A5-1 | 객관식(단일) | 보기 하나만 선택 가능 | 다른 보기 선택 시 이전 선택 해제 |
| A5-2 | 객관식(다중) | 보기 여러 개 선택 가능 | 체크박스로 복수 선택되고 그대로 제출됨 |
| A5-3 | OX | O 또는 X 선택 | 두 개 중 하나만 선택 가능 |
| A5-4 | 주관식 | 텍스트 직접 입력 | 정답 목록 중 하나와 일치하면 정답 처리(띄어쓰기·완전일치 기준 확인) |
| A5-5 | 빈칸 채우기 | 빈칸 여러 개에 각각 입력 | "N개 중 M개 입력" 표시가 입력할 때마다 실시간으로 바뀜, 일부만 입력하고 제출 시도 시 안내 |
| A5-6 | 참조지문이 있는 문제 | 지문이 길 경우 | 접혀 있고 "더 보기"로 펼쳐짐 |
| A5-7 | 이미지가 있는 문제 | 이미지 문제 하나 이상 풀어보기 | 이미지가 깨지지 않고 로드됨(안 뜨면 §5 양식대로 문제 번호·부서 기록) |
