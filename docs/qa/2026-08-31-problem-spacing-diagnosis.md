# 문제 텍스트 띄어쓰기 전수 진단

- 작성일: 2026-08-31
- 대상: 로컬 개발 DB `probank_dev` 의 문제 705문항 전체
- 스캔 범위: 문제 본문 · 참조 지문 · 해설 · 보기 · 정답 · 빈칸 정답 — **텍스트 조각 2,872개**
- 성격: **진단 전용. 어떤 데이터도 수정하지 않았다.**

## 1. 결론

문제 텍스트 전반에 **PDF 줄바꿈이 공백으로 치환된 변환 아티팩트**가 남아 있다.
줄이 바뀐 자리가 단어 중간이든 조사 앞이든 상관없이 공백이 되어, `외면 으로부터`,
`판 매열량`, `위험 요 소` 같은 형태로 굳었다.

| 판정 | 건수 | 영향 문항 |
|---|---|---|
| **확실** — 어절 첫머리에 올 수 없는 조사 | 309건 | 226문항 |
| **의심** — 홀로 설 수 없는 1음절 조각 | 295건 | 201문항 |
| **합계** | **604건** | **343문항 / 705문항 (48.7%)** |

**전체 문항의 약 절반이 최소 한 곳 이상 영향을 받았다.**

## 2. 원인 — 재임포트로는 고쳐지지 않는다

원본 변환 파일 `docs/문제은행_엑셀/문제_01_공통.xlsx` 를 직접 열어 확인한 결과,
**엑셀에도 같은 아티팩트가 그대로 들어 있다.**

```
xlsx 원본 : 배관을 철도부지에 매설하는 경우 배관의 외면 으로부터 궤도중심까지의 …
DB       : 배관을 철도부지에 매설하는 경우 배관의 외면 으로부터 궤도중심까지의 …
```

즉 오염은 DB 적재가 아니라 **2026-08-09 PDF→엑셀 변환 시점**에 생겼다.
DB 를 다시 적재해도 같은 결과가 나온다. 원본 PDF 재추출은
spec `2026-08-13-source-number-and-random-50.md` §2.3 이 "본문 스트림은 배포용 보호가
걸려 있다"고 적어 두었으므로 별도 확인이 필요하다.

## 3. 판정 기준과 한계

**확실** — 어절이 한국어에서 어절 첫머리에 올 수 없는 형태로 시작하는 경우.
1음절 조사(`의 을 를 은 는 이 가 에 와 과 도 만 로 며`)가 홀로 선 경우와
`으로 에서 에게 부터 까지 이라 으며 에는 …` 로 시작하는 경우다.

**의심** — 1음절 어절인데 홀로 쓰이는 낱말 목록에 없는 경우.
`수 것 등 및 년 월 일 …` 같은 자립 명사와 `할 한 될 된 …` 같은 관형형은 제외했다.

> **이 수치는 하한선이다.** 아티팩트는 줄바꿈 위치에서 무작위로 발생하므로,
> `위약 금을` 처럼 양쪽 다 2음절 이상이면서 조사도 아닌 지점에서 끊긴 것은
> 규칙으로 잡히지 않는다. 실제 오류는 604건보다 많다.

**알려진 오탐이 있다.** `이` 를 관형사로 쓴 `이 혁명은?` 같은 사례가 확실 버킷에
섞여 있다(전체 `이` 28건 중 일부). 목록을 그대로 일괄 적용하면 안 된다.

## 4. 자동 교정이 위험한 이유

**붙이는 방향이 일정하지 않다.** 아래 두 사례는 같은 규칙에 걸리지만 고치는 방향이 반대다.

| 원문 | 올바른 교정 | 방향 |
|---|---|---|
| `배관의 외면 으로부터` | `외면으로부터` | 앞 어절과 결합 |
| `발생할 수 있는 가 스공급량의` | `가스공급량의` | **뒤 어절과 결합** |

앞 어절과 무조건 붙이면 두 번째는 `있는가 스공급량` 이 되어 더 나빠진다.
그래서 이 보고서는 **교정안이 아니라 위치만** 제시한다.
