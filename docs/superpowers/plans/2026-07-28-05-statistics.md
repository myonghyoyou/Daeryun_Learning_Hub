# 문제 은행 Hub — Plan 5: 통계 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 관리자가 문제별 정답률/오답률을 한눈에 보고, 정답률이 낮은 문제를 우선적으로 파악하며, 문제 상세에서 보기별 선택 분포와 최근 오답 샘플까지 확인할 수 있게 한다.

**Architecture:** Plan 4에서 쌓이는 `attempts`(및 `attempt_blank_answers`) 데이터를 집계한다. 집계는 SQL로 카운트만 뽑고, 정답률 계산·정렬·보기별 분포 집계는 서비스 계층(Java)에서 수행해 SQL을 단순하게 유지한다. 부서 관리자는 자기 부서 문제만, 총괄 관리자는 전체(+부서 필터)를 조회한다 (Plan 1의 `@RequireRole`, Plan 3의 부서 스코프 패턴 재사용).

**Tech Stack:** Plan 1~4와 동일

**전제 조건:** Plan 1, Plan 3, Plan 4가 완료되어 있어야 한다.

## Global Constraints

- MVP 핵심 지표는 **문제별 정답률/오답률**이다. 정답률이 낮은 문제를 상위에 정렬해 보여준다 (PRD 섹션 5.1).
- 부서 관리자는 자기 부서 문제 통계만, 총괄 관리자는 전체(+부서 필터) 통계를 조회한다 (섹션 5.2).
- 상세 화면은 문제별 총 시도 수/정답 수/정답률/최근 시도일과, 보기별 선택 분포(객관식/OX), 최근 오답 제출 샘플을 보여준다 (섹션 5.3).
- 개인별/부서별 비교 통계, 응시율, 기간별 추이는 이번 범위 밖이다 (섹션 5.4, 10).

## Design System Implementation Contract

프론트엔드 통계 화면은 `docs/superpowers/specs/2026-07-29-blue-bento-design-system.md`를 단일 기준으로 사용한다. 대상 화면은 디자인 시스템 8.6 관리자 Shell·대시보드, 8.11 통계 목록·상세와 9.3 관리자 반응형 규칙이다.

- 통계 화면은 관리자 Shell과 컴팩트한 업무 밀도를 유지한다. 정답률·오답률·시도 수·최근 시도일은 숫자만 나열하지 않고 적용 범위와 기준을 함께 표시한다.
- 통계 목록은 정답률 낮은 문제 우선 정렬, 부서 필터, 문제 유형·상태 정보가 빠르게 비교되도록 구성한다. 상세 화면은 Summary metric, 보기별 분포, 최근 오답 샘플을 계층적으로 배치한다.
- 총괄 관리자와 부서 관리자의 필터 노출 차이를 메뉴·필터·권한 없음 상태에 일관되게 반영한다. 부서 관리자는 자기 부서 범위만 표시한다.
- 로딩 시 Header·필터 위치는 유지하고 metric·표·상세 영역만 Skeleton 처리한다. 데이터 없음, 조회 오류, 권한 없음, 세션 만료 상태와 다음 행동을 제공한다.
- 완료 기준에는 PC 1440×1024 기준의 통계 목록·상세와 모바일 접근 차단, 정답률 정렬, 부서 필터, 빈 상태, 키보드 포커스, 숫자 가독성 및 Design QA를 포함한다.

package com.daeryun.probank.dto.stats;

import com.daeryun.probank.domain.ProblemType;
import lombok.AllArgsConstructor;
import lombok.Data;

import java.time.LocalDateTime;

@Data
@AllArgsConstructor
public class ProblemStatItem {
    private Long problemId;
    private String content;
    private ProblemType type;
    private Long departmentId;
    private String departmentName;
    private int totalAttempts;
    private int correctAttempts;
    private Double accuracyRate;
    private LocalDateTime lastAttemptAt;

    public static ProblemStatItem from(ProblemStatRaw raw) {
        Double accuracyRate = raw.getTotalAttempts() == 0
                ? null
                : (double) raw.getCorrectAttempts() / raw.getTotalAttempts();
        return new ProblemStatItem(raw.getProblemId(), raw.getContent(), raw.getType(), raw.getDepartmentId(),
                raw.getDepartmentName(), raw.getTotalAttempts(), raw.getCorrectAttempts(), accuracyRate, raw.getLastAttemptAt());
    }
}

package com.daeryun.probank.service;

import com.daeryun.probank.common.AuthUser;
import com.daeryun.probank.dao.AttemptDao;
import com.daeryun.probank.dao.ProblemChoiceDao;
import com.daeryun.probank.dao.ProblemDao;
import com.daeryun.probank.dao.StatsDao;
import com.daeryun.probank.domain.UserRole;
import com.daeryun.probank.dto.stats.ProblemStatItem;
import org.springframework.stereotype.Service;

import java.util.Comparator;
import java.util.List;
import java.util.stream.Collectors;

@Service
public class StatsServiceImpl implements StatsService {

    private final StatsDao statsDao;
    private final AttemptDao attemptDao;
    private final ProblemDao problemDao;
    private final ProblemChoiceDao problemChoiceDao;

    public StatsServiceImpl(StatsDao statsDao, AttemptDao attemptDao,
                            ProblemDao problemDao, ProblemChoiceDao problemChoiceDao) {
        this.statsDao = statsDao;
        this.attemptDao = attemptDao;
        this.problemDao = problemDao;
        this.problemChoiceDao = problemChoiceDao;
    }

    @Override
    public List<ProblemStatItem> listProblemStats(AuthUser actor, Long departmentId) {
        Long effectiveDepartmentId = actor.getRole() == UserRole.SUPER_ADMIN ? departmentId : actor.getDepartmentId();
        return statsDao.findProblemStats(effectiveDepartmentId).stream()
                .map(ProblemStatItem::from)
                .sorted(Comparator.comparing(
                        (ProblemStatItem item) -> item.getAccuracyRate() == null ? Double.MAX_VALUE : item.getAccuracyRate()))
                .collect(Collectors.toList());
    }
}

package com.daeryun.probank.service;

import com.daeryun.probank.common.AuthUser;
import com.daeryun.probank.common.ErrorCode;
import com.daeryun.probank.dao.AttemptDao;

import com.daeryun.probank.domain.Problem;
import com.daeryun.probank.domain.ProblemChoice;
import com.daeryun.probank.domain.ProblemType;
import com.daeryun.probank.domain.UserRole;
import com.daeryun.probank.dto.stats.*;
import com.daeryun.probank.exception.BizException;
import org.springframework.stereotype.Service;

import java.util.Arrays;
import java.util.Comparator;
import java.util.List;
import java.util.Map;
import java.util.stream.Collectors;

@Service
public class StatsServiceImpl implements StatsService {

    private static final int RECENT_WRONG_LIMIT = 5;

    private final StatsDao statsDao;
    private final AttemptDao attemptDao;
    private final ProblemDao problemDao;
    private final ProblemChoiceDao problemChoiceDao;

    public StatsServiceImpl(StatsDao statsDao, AttemptDao attemptDao, ProblemDao problemDao, ProblemChoiceDao problemChoiceDao) {
        this.statsDao = statsDao;
        this.attemptDao = attemptDao;
        this.problemDao = problemDao;
        this.problemChoiceDao = problemChoiceDao;
    }

    @Override
    public List<ProblemStatItem> listProblemStats(AuthUser actor, Long departmentId) {
        Long effectiveDepartmentId = actor.getRole() == UserRole.SUPER_ADMIN ? departmentId : actor.getDepartmentId();
        return statsDao.findProblemStats(effectiveDepartmentId).stream()
                .map(ProblemStatItem::from)
                .sorted(Comparator.comparing(
                        (ProblemStatItem item) -> item.getAccuracyRate() == null ? Double.MAX_VALUE : item.getAccuracyRate()))
                .collect(Collectors.toList());
    }

    @Override
    public ProblemStatDetailResponse getProblemDetail(Long problemId, AuthUser actor) {
        Problem problem = problemDao.findById(problemId);
        if (problem == null) {
            throw new BizException(ErrorCode.INPUT_VALUE_INVALID, "존재하지 않는 문제입니다.");
        }
        if (actor.getRole() != UserRole.SUPER_ADMIN && !problem.getDepartmentId().equals(actor.getDepartmentId())) {
            throw new BizException(ErrorCode.ACCESS_AUTH_DENIED);
        }

        ProblemStatItem summary = statsDao.findProblemStats(problem.getDepartmentId()).stream()
                .filter(raw -> raw.getProblemId().equals(problemId))
                .map(ProblemStatItem::from)
                .findFirst()
                .orElseGet(() -> new ProblemStatItem(problem.getId(), problem.getContent(), problem.getType(),
                        problem.getDepartmentId(), null, 0, 0, null, null));

        List<ChoiceDistributionItem> choiceDistribution = null;
        if (problem.getType() == ProblemType.MCQ_SINGLE || problem.getType() == ProblemType.MCQ_MULTI
                || problem.getType() == ProblemType.OX) {
            List<ProblemChoice> choices = problemChoiceDao.findByProblemId(problemId);
            List<String> rawAnswers = attemptDao.findRawByProblemId(problemId);
            Map<Long, Long> countsByChoiceId = rawAnswers.stream()
                    .flatMap(answer -> Arrays.stream(answer.split(",")))
                    .filter(s -> !s.trim().isEmpty())
                    .map(s -> Long.parseLong(s.trim()))
                    .collect(Collectors.groupingBy(id -> id, Collectors.counting()));
            choiceDistribution = choices.stream()
                    .map(choice -> new ChoiceDistributionItem(
                            choice.getId(), choice.getChoiceText(),
                            countsByChoiceId.getOrDefault(choice.getId(), 0L).intValue()))
                    .collect(Collectors.toList());
        }

        List<RecentWrongSample> recentWrongSamples = attemptDao.findRecentWrong(problemId, RECENT_WRONG_LIMIT);
        if (choiceDistribution != null) {
            Map<Long, String> choiceTextById = problemChoiceDao.findByProblemId(problemId).stream()
                    .collect(Collectors.toMap(ProblemChoice::getId, ProblemChoice::getChoiceText));
            recentWrongSamples.forEach(sample -> sample.setDisplayAnswer(Arrays.stream(sample.getSubmittedAnswer().split(","))
                    .map(String::trim).filter(s -> !s.isEmpty()).map(id -> choiceTextById.getOrDefault(Long.valueOf(id), id))
                    .collect(Collectors.joining(", "))));
        } else {
            recentWrongSamples.forEach(sample -> sample.setDisplayAnswer(sample.getSubmittedAnswer()));
        }

        return new ProblemStatDetailResponse(summary, choiceDistribution, recentWrongSamples);
    }
}
