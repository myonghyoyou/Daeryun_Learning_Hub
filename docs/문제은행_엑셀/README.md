# 2025 문제은행(행정직) → 엑셀 일괄등록 변환 결과

원본 `★2025 문제은행(행정직) - 배포용.pdf`(44p, 12개 그룹, 722문항)를 관리자 화면
**「문제 엑셀 일괄 등록」** 형식으로 변환한 결과물입니다.

## 산출물

| 파일 | 내용 |
|---|---|
| `문제_01_공통.xlsx` ~ `문제_12_공사관리팀.xlsx` | **그룹(팀)별 업로드용 엑셀** — 총 653행. 서버 검증 규칙 100% 통과 확인 |
| `_미업로드_주관식빈칸_수동입력.xlsx` | 엑셀로 올릴 수 없어 **개별 등록 화면에서 수동 입력**해야 하는 69문항 |
| `_검증로그.txt` | 그룹별 처리 내역 + 수동 확인이 필요한 행 목록 |

- 업로드 653 + 수동 69 = **722문항 전부 반영**(누락 없음).

## 엑셀 컬럼 (1행 헤더 · 2행부터 데이터)

`문제유형 | 문제내용 | 이미지 | 참조지문 | 보기1~5 | 정답 | 해설 | 태그`

- **문제유형**: `MCQ_SINGLE`(객관식 단일) / `MCQ_MULTI`(복수정답) / `OX` / `SHORT_ANSWER`(단답)
- **정답**: 객관식·OX는 보기 번호(1부터), 복수는 콤마 / 단답은 허용정답 목록(콤마)
- **이미지 열은 비움**(엑셀로 이미지 등록 불가)
- **태그**: 팀명

## 업로드 방법

1. 관리자 로그인 → **문제 관리 → 문제 엑셀 일괄 등록**
2. `문제_NN_*.xlsx`를 하나씩 업로드(파일당 최대 500행, 모두 그 이하)
3. 결과의 성공/실패 건수 확인

> ⚠️ **부서 귀속 주의**: 업로드된 문제는 전부 **로그인한 관리자의 부서**로 귀속됩니다.
> (엑셀에 부서 열이 없음) 팀별로 분리해 두었으니, **각 팀 문제는 해당 팀 관리자 계정으로
> 로그인해서** 올리면 부서 격리가 맞습니다. 공통 문제는 원하는 부서에 올리세요.

## 수동 입력 대상 69문항 (`_미업로드_...xlsx`)

| 사유 | 건수 | 설명 |
|---|--:|---|
| 다중빈칸(FILL_BLANK) | 50 | `( )…( )…( )`처럼 빈칸이 여러 개인 문제. 엑셀 업로드 미지원 → 개별 등록의 빈칸채우기로 입력 |
| 객관식 보기추출 실패/빈칸형 | 8 | 정답은 숫자지만 보기가 원문에서 표/수식 형태라 자동 추출 실패 → 원본 확인 후 입력 |
| 본문 파싱 실패 | 11 | 병합문항(`11-12.`)·O/X 묶음 문제 등 형식이 특이해 자동 매칭 실패 → 원본 확인 후 입력 |

각 행에 그룹·문항번호·정답(참고)·문제내용(참고)이 있어 원본 PDF와 대조해 입력하면 됩니다.

## 알려진 한계 (검수 시 참고)

- **줄바꿈 공백**: 원문이 단어 중간에서 줄바꿈된 곳은 합칠 때 공백이 남을 수 있음(예: "말한 다.").
  의미·업로드에는 영향 없음. 필요 시 엑셀에서 찾기·바꾸기로 정리.
- **참조지문/표**: 지문·SWOT 표가 있는 문제는 `문제내용` 안에 함께 들어감(참조지문 열 미사용).
- **해설**: 정답표의 부가설명(예: "IFRS: 국제회계기준의 약자")만 해설 열에 반영.

*생성 방식: PDF 4단 레이아웃을 컬럼 단위로 분리 추출 → 그룹별 문제/정답표 파싱 →
유형 분류 → 서버 검증 규칙으로 자동 검수.*
